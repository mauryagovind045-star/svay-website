# Svay Studio — Website

Website for **Svay Studio**, an interior design studio by Simran Siriskar (Goa / Mumbai, India).

> *Svay* comes from the Sanskrit word **Svayam**, meaning *self* — every space should be a reflection of the individual who inhabits it.

## Brand & design direction

- Warm neutral palette: cream/ivory, greige, taupe, camel accents, deep espresso/charcoal contrast sections
- Editorial serif display typography (italic serif accents), minimal sans body
- Quiet-luxury aesthetic: full-bleed interior photography, giant wordmark treatment, arches, biophilic motifs
- Primary layout reference: COLLISON-style editorial structure (oversized wordmark over hero, line-art service cards, photo↔technical-sketch overlays, stats band, dark footer)
